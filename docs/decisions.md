# Decisions

Decisions taken on cozy-libs, oldest first, for every package of the repository: an entry names the packages it covers in its Scope line. Append only: a decision that changes gets a new entry that replaces the old one and cites it. Entry format: the `twake-decisions` skill of [linagora/twake-guidelines](https://github.com/linagora/twake-guidelines/blob/main/skills/twake-decisions/SKILL.md).
